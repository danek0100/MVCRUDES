# `PARAMI`

## Обзор
`PARAMI` используется для представления и хранения параметров с именами и соответствующими им числовыми значениями.

## Основные Характеристики
- **Имя модели:** `PARAMI`
- **Необходимость провайдера:** Да (`NeedProvider: true`)

## Поля

### `NAME`
- **Тип данных:** String
- **Максимальная длина:** 250 символов
- **Обязательное поле:** Да (`CanBeEmpty: false`)
- **Описание:** Уникальное имя параметра.

### `PARAMVALUE`
- **Тип данных:** Number
- **Обязательное поле:** Да (`CanBeEmpty: false`)
- **Значение по умолчанию:** 0 (`DefaultValue: "0"`)
- **Описание:** Числовое значение, связанное с параметром.
