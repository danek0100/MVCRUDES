# Документация по Сущностям Системы

## Введение
Сущности в данной системе служат для унифицированного взаимодействия между сервером и клиентом, обеспечивая эффективный обмен информацией об объектах и их изменениях. Сущности позволяют серверу управлять данными и предоставлять обновления клиентам, что облегчает процесс синхронизации. Клиенты, в свою очередь, используют предоставленный сервером CRUD интерфейс, автоматически генерируя редакторы для сущностей, что снижает необходимость в написании дополнительного кода. Благодаря сущностям и дополнительным знаниям о структуре могут быть сгенерированы таблицы в разных базах данных.

## Структура Сущностей

### Основная Сущность
- Расположение: `entity/entity_name.json`
- Содержит:
    - `Name`: Название сущности.
    - `NeedProvider`: Указывает, требуется ли провайдер для сущности.
    - `Version`: Текущая версия сущности.
    - `Fields`: Описание полей сущности, включая:
        - `Name`: Название поля (обязательное).
        - `Type`: Тип данных поля (обязательное).
        - `Length`: Длина поля (обязательная для типа `String`).
        - `CanBeEmpty`: Указывает, может ли поле быть пустым (опциональное).
        - `DefaultValue`: Значение по умолчанию (опциональное).
        - `IsUnique`: Уникальность значения поля (опциональное).
- Доступные типы: `Number`, `String`.

### Значения по Умолчанию
- Расположение: `defaults/entity_name.json`
- Содержит значения, которые будут автоматически добавлены в таблицу при её создании.
- Пример структуры:
  ```json
  {
    "TableName": "ENTITY_NAME",
    "DefaultValues": [
      {
        "FIELD_NAME": "value"
        // Другие поля...
      }
    ]
  }
  ```

### Руководство по Использованию
- Для создания новой сущности следуйте структуре entity/entity_name.json.
- Если сервер не должен нести ответсвенность за добавление значений по умолчанию, создание и обновление таблицы сущности, укажите версию -1.
- Для инициализации начальных значений используйте defaults/entity_name.json.

### Версионирование и Обновления
- При внесении изменений в сущность, увеличивайте версию в entity/entity_name.json.
- Отслеживайте и документируйте все изменения для ясности и удобства отслеживания.
